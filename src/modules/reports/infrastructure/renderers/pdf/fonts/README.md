# Fontes Estáticas do RM Frotas (Exportação PDF)

Arquivos TTF estáticos necessários para a renderização offline com `@react-pdf/renderer`.
Fontes variáveis não são suportadas pelo `react-pdf`, por isso são utilizados apenas binários TTF estáticos sem eixos variáveis (`[wght]`).

## Inter
- **Versão:** v4.1
- **Origem:** [rsms/inter releases](https://github.com/rsms/inter/releases/tag/v4.1)
- **Licença:** SIL Open Font License (OFL) v1.1 (`LICENSE-Inter.txt`)
- **Arquivos e Pesos:**
  - `Inter-Regular.ttf` -> `fontWeight: 400`
  - `Inter-SemiBold.ttf` -> `fontWeight: 600`
  - `Inter-Bold.ttf` -> `fontWeight: 700`
